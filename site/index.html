Verso letras sincronizadas · para Spotify

A letra, no tempo da música.

Um app pequeno e gratuito que mostra a letra sincronizada do que está tocando no Spotify (ou no YouTube Music, no Windows), flutuando por cima de qualquer janela — do editor de código ao navegador.

Baixar para macOS Baixar para Windows

Mac com Intel? Baixe esta versão. Todas as versões em Releases.

Funciona com Music, no Windows

Lado A O que ele faz

  1. 01Sincroniza com o Spotifye YouTube Music no Windows
  2. 02Fica por cima de todas as janelassem roubar o clique
  3. 03Traduz a letra para português, inglês ou espanholoriginal, tradução ou os dois
  4. 04Cinco fontes, inclusive manuscritaPreferências
  5. 05Tamanho, cor do texto e fundo da linha atualPreferências
  6. 06Arraste para onde quiser na tela⌘⇧L
  7. 07Letra adiantada ou atrasada? Ajuste por faixa⌘⌥⇧←→
  8. 08Mora na barra de menus, sem janela no Dockbandeja no Windows

No Windows, use Ctrl no lugar de ⌘ e Alt no lugar de ⌥.

Lado B Instalar

macOS

  1. Abra o .dmg e arraste o app para Aplicativos.
  2. Na primeira vez, clique com o botão direito no app e escolha Abrir. O app não é assinado pela Apple, então o duplo clique é bloqueado só nessa primeira abertura.
  3. Quando o macOS perguntar, permita que o Verso controle o Spotify. É assim que ele sabe o que está tocando.

Windows

  1. Rode o instalador .exe.
  2. Se o SmartScreen avisar, clique em Mais informações e depois em Executar assim mesmo.
  3. Toque algo no app do Spotify para Windows ou no YouTube Music pelo navegador. A letra aparece sozinha.
